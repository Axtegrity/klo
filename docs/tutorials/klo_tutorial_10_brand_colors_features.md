# Tutorial 10: Customizing Brand Colors and Features
**Duration estimate:** 8 minutes
**Series:** KLO Admin Video Tutorials

---

## Prerequisites

Before you start this tutorial, you need:
- Admin access (see Tutorial 01)
- If changing brand colors: your hex color codes ready (for example, #C8A84E for gold)
- The admin dashboard open at keithlodom.ai/admin

---

## What You Will Learn

By the end of this video, you will know how to open the Customize tab, change the site's brand colors, and turn individual features and pages on or off without any coding.

---

## Step-by-Step Instructions

### Step 1 — Open the Customize tab

1. Click the **Customize** tab in the tab row at the top of the admin dashboard.

[SHOW: the tab row with Customize highlighted]
[NARRATE: "The Customize tab is divided into two panels: Brand Colors and Pages and Features. You switch between them using the two buttons at the top."]

---

### Step 2 — Read the two panels

At the top of the Customize tab, you will see two buttons:

| Button | What it controls |
|---|---|
| **Brand Colors** | The primary, accent, and supporting colors used throughout the site |
| **Pages & Features** | Which pages and features are visible and active for members |

[SHOW: the two panel buttons — Brand Colors and Pages & Features]

---

### Step 3 — Open Brand Colors

1. Click **Brand Colors** if it is not already selected.

The Brand Colors panel will open. You will see a list of color settings. Each one has:
- A label (for example, "Primary Color" or "Accent Color")
- A color preview swatch showing the current color
- A hex code input field where you can type a new color value

[SHOW: the Brand Colors panel with color swatches and hex fields]
[NARRATE: "A hex code is the six-character code that defines a color exactly — for example, #C8A84E is the gold used on the site. If your brand has a style guide with hex codes, use those. If not, you can Google 'hex color picker' to find codes for any color."]

---

### Step 4 — Change a brand color

1. Find the color you want to change — for example, the accent or gold color.
2. Click in the hex code field next to that color.
3. Delete the existing code.
4. Type your new hex code, including the # symbol — for example: `#D4A853`.
5. The preview swatch will update to show the new color.
6. Click the **Save** button (or the button labeled **Save Colors** — the exact label depends on how your panel is configured) to apply the change.

[SHOW: a hex code being changed and the swatch updating]
[NARRATE: "Color changes apply site-wide. If you change the accent color, every button, badge, and highlight that uses that color will update. Preview carefully before saving — this affects the entire look of the site."]

---

### Step 5 — Open Pages and Features

1. Click the **Pages & Features** button to switch panels.

The Pages and Features panel shows a list of every page and feature on the site. Each one has a toggle switch.

[SHOW: the Pages & Features panel with toggle switches visible]

---

### Step 6 — Read the toggles

Each row in the Pages and Features panel represents one part of the site. The toggle on the right of each row controls whether that feature is:

- **On (blue)** — active and visible to members
- **Off (grey)** — hidden from members

Examples of what you might see:

| Feature / Page | What it controls |
|---|---|
| **Vault Library** | The content vault for subscribers |
| **AI Advisor** | The AI chat assistant feature |
| **Assessments** | The four leadership assessment tools |
| **Strategy Rooms** | The collaborative strategy session feature |
| **Events** | The public events and conference page |
| **Booking** | The speaker booking inquiry form |

[SHOW: the toggles with some on and some off]
[NARRATE: "Turning a feature off hides it from members but does not delete any data. If you turn the Vault off, members cannot access it — but all the content is still in the database and will be visible again when you turn it back on."]

---

### Step 7 — Toggle a feature on or off

1. Find the feature you want to change.
2. Click the toggle switch on the right side of that row.
3. The toggle will switch from blue to grey (off) or grey to blue (on).
4. Look for a **Save** confirmation button or toast — click it if prompted.

[SHOW: a toggle being clicked from on to off]
[NARRATE: "Most toggles save immediately when clicked. Watch for a brief confirmation message to confirm the change went through."]

---

### Step 8 — Verify the change on the live site

After changing colors or toggling features:

1. Open a new browser tab.
2. Go to **keithlodom.ai**.
3. Confirm the new color or the feature change is visible.

For feature toggles: try navigating to the feature's page from the main navigation. If you turned it off, it should no longer appear in the menu or be accessible.

[SHOW: the live site reflecting the color or feature change]

## Important Cautions

**Brand Colors:**
- Color changes are instant and site-wide. They affect what every member sees immediately.
- Only change colors if you have the correct hex codes from a design brief or brand guide.
- If you make a mistake, type the original hex code back in and save again.

**Pages and Features:**
- Turning off a page hides it from members immediately.
- Do not turn off the Vault, Assessments, or AI Advisor unless you have a specific reason — these are core features your subscribers pay for.
- When in doubt, consult Keith or your developer before turning off features.

---

## Troubleshooting

**Problem: I typed a hex code but the color swatch did not update.**
Fix: Make sure the hex code starts with # and is exactly 6 characters after it — for example, #FF5733. Hex codes with fewer than 6 characters will not work.

**Problem: I turned off a feature but members can still see it.**
Fix: Some browsers cache the navigation. Ask the member to do a hard refresh (Ctrl+Shift+R on Windows, Cmd+Shift+R on Mac). Also confirm you saved the toggle change successfully.

**Problem: The Save Colors button is not appearing.**
Fix: Make sure you actually clicked in the hex field and changed a value. The Save button only activates when a change is detected.
